# v6.1buildguide.md - Offcut V6.1 "Long source": step-by-step build guide

## What this is

`docs/v6.1/v6.1implementation.md` says what each file contains and why. This guide says what to do next, which command to run, and how to know it worked. The release is built on `v6.1-build`, with a draft pull request into `main` so that CI runs. It ends with the pull request merged, deployed **dark** (both new flags off in production), the live checks passed, every box of the plan's §17 ticked except the founder's morning steps, and the tag `v6.1` pushed.

**It is built in one unattended night** under `docs/v6.1/overnight-run.md`, which holds the authorisations (merge, tag) and replaces every "stop and ask" with a safe path. This guide and `coding-promptsv6.1.md` are written so that an agent alone can follow them: every founder decision is already taken (plan §15), and every human step has an agent's replacement or is left for the morning.

## Read this first: 22 things that will bite you

1. **Flags default to off** (D-393). Never make `long_video` or `high_res` default on, never set `OFFCUT_FEATURES_ON` in `.env`, CI's production build or Vercel. Production's flags change only by the founder's step of §12.3.
2. **The clip path's files are untouchable by name** (D-387): `validate_probe`, `probe_and_validate`, `open_demuxer`, `resample_mono`, `decodeAudio`, `importToOpfs`, `importAndProbe`, `extractAudio`, `run-pipeline.ts`, `whisper-runtime.ts`, `word-timestamps.ts`, `transcribe-cloud.ts`. `git diff -w $BASE -- <file>` shows additions only, or nothing.
3. **IndexedDB:** `DB_VERSION` stays 1. Only `sources-repo.ts` opens structure version 2 (D-414). A test opens the database through the clip path only and asserts it is still version 1.
4. **A `File` never goes into a store, IndexedDB, OPFS, a URL or a log.** Its name is never read (P-11). The hand-over is a module variable (D-421).
5. **The demuxer must not see the File through a copy.** `routeFile` reads in place; if a buffer of the whole file appears anywhere, the design is broken.
6. **`decodeAudio`'s one big buffer is the thing the long path must not do** (D-401): about 520 MB for 45 minutes.
7. **The fake API's defaults stay as they are** (CT G item 3): `/healthz` without `cloud_transcribe`, `/transcribe` unanswered. Long-path specs turn the options on.
8. **The window header changes nothing without it** (D-411, D-413): every existing `transcribe_route.rs` case passes unchanged, and a clip's request bytes are identical.
9. **Removing the route's IP layer moves the check, it does not drop it** (D-411): the IP bucket runs in the handler before the body is read; `rate_limit.rs`' table test and a 61st-request case prove it.
10. **Never send to Groq** anything but the reference clip's audio (looped) or a tone (F-1, CT D-379). Never `testclips/v3testclip*`, `WIN_*`, a corpus clip, or the founder's HDR clip. Each real call is listed in V6 CL with its seconds of audio.
11. **Never print, log, commit or paste a key.** A script that needs the Groq key reads `TRANSCRIBE_API_KEY` alone from `.env.deploy` and prints names, status codes and times only; `.env.deploy` is never sourced whole (it holds the real mail relay, billing settings and the production database's address). `git grep -nE "gsk_[A-Za-z0-9]{20}"` before every commit: no output.
12. **`messages.ts` is 668 of 700 lines.** New copy goes in `copy/long.ts` (D-426); `messages.ts` gains only imports and the new codes' entries, which may also live in `long.ts`.
13. **Media suites run on keyed builds.** `export VITE_ENTITLEMENT_TEST_PUBLIC_KEY=...` (ci.yml's value, read non-greedily: its line ends in `# gitleaks:allow`) before `pnpm build:e2e` **and** `pnpm build:e2e:flags`, from Git Bash. Unset it before committing.
14. **Playwright wipes `web/test-results/` every run.** Copy captures out to `~/v6.1-review/` first.
15. **D1's e2e is load-sensitive.** `--workers=4` for `pnpm e2e`; rerun a failure alone before believing it.
16. **`target/` grows huge** (memory: 84 GB once). `cargo test -p <crate> --test <file>` per prompt; the workspace only in Setup and P182. `cargo clean -p` a crate if `target/` passes 30 GB.
17. **Docs and the changelog are edited with the Edit tool.** Never Python on Windows (CRLF), never a heredoc that holds backticks.
18. **The 45-minute 4K fixture is about 1.4 GB:** in `fixtures/.gen-local/`, never staged, never in CI. **It is not git-ignored at `afb82bf`:** P171 adds `fixtures/.gen-local/` to `.gitignore` before writing anything there, and P173 adds `web/dist-flags/`. Check with `git check-ignore`.
19. **`gen_fixtures.sh` runs on every CI pull request** (83-94 s today). The four new fixtures must add under 60 s: tiny resolution, `-preset ultrafast`, 1 fps for the 46-minute file.
20. **An unattended night cannot sleep the laptop.** TE-20's sleep is simulated with CDP (`Page.setWebLifecycleState`), and the real sleep test is a morning step (ON §8).
21. **An unattended night cannot sign in to a local API** (no inbox). Every product run uses the fake API's signed-in session; real Groq calls go through the scratch proxy of Phase 11.
22. **pnpm scripts run in `cmd.exe` on Windows.** An environment prefix (`VAR=x cmd`) needs `sh -c "…"`, as the `dev` script does (G 3.3).
