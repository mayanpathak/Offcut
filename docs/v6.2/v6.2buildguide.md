# v6.2buildguide.md - Offcut V6.2 "AI edit plan": step-by-step build guide

## What this is

`docs/v6.2/v6.2implementation.md` says what each file contains and why. This guide says what to do next, which command to run, and how to know it worked. The release is built on `v6.2-build`, with a draft pull request into `main` so that CI runs. It ends with the pull request merged, deployed **dark** (`ai_plan` and `motion` off in production, `PLAN_ENABLED=false` on Render), the live checks passed, every box of the plan's §19 ticked, and the tag `v6.2` pushed.

**It is built by hand, carefully, one prompt at a time** (the founder's decision of 2026-11-11, D-434). There is no overnight run. A prompt starts only when the one before has its commit and every acceptance box ticked. When a proof fails, stop: fix it inside the prompt, or ask the founder. Never carry a red test into the next prompt, and never shorten a step to save time.

**The AI provider is DeepSeek, with thinking always off** (the founder's decision of 2026-11-11, D-500). Wherever this guide says Gemini or Google's API, read DeepSeek (`api.deepseek.com`, key `PLAN_API_KEY2` until it is renamed); Google's terms and prices are replaced by D-500's and D-492's notes.

## Read this first: 24 things that will bite you

1. **Flags default to off** (V6.1 D-393). `ai_plan` and `motion` are `false` in `DEFAULTS`. Never set `OFFCUT_FEATURES_ON` in `.env`, CI's production build or Vercel. `PLAN_ENABLED` stays `false` on Render at the merge.
2. **The five kinds are not behind a flag; their producer is** (D-443). A rules plan never contains them. If any existing snapshot or golden moves, a new code path is reachable from an old input: that is a bug, not a regeneration.
3. **Never regenerate a golden or snapshot that exists at `b73fea5`.** `OFFCUT_GOLDEN_UPDATE=1` and `cargo insta accept` may only add files, or update a file this release added (the `@v2` snapshots made in P186 and updated in P187). Before a commit: `git diff --name-only --diff-filter=MD $BASE -- '*.snap' '*.png'` prints nothing.
4. **`EditState`'s JSON must not change for `Enhance::v5()`** (D-485): `skip_serializing_if`. The render-cache key hashes it; stored records hold it; `edit_state_round_trips_with_ids_as_map_keys` pins it.
5. **The existing tests that may change are exactly D-440's nine.** Any other failing existing test means the change is wrong.
6. **`catalog_complete.rs` is ignored from P186 to P206 only** (D-440 (9)). `git grep -n 'ignore = "V6.2' crates` after P206 prints nothing.
7. **`motion.rs` is the caption motion of V4.** The camera drift is `camera.rs` (D-476). Do not put the drift in `motion.rs`.
8. **`easing.rs`' `Easing` enum and `ease()` do not change** (D-475). The bezier is beside them.
9. **Images go through the Vello overlay, not the compositor** (D-472). `video_pass.rs` and the compositor's video draw have an empty diff.
10. **No scene code emits `DrawCmd::Image` before P204,** after TE-30 passed in the browser and CI's lavapipe passed the image golden (P197's waited push).
11. **The Gemini key.** Its name becomes `PLAN_API_KEY` in Setup (F-1). Never print, log, commit or paste its value; never `cat` `.env` or `.env.deploy`; read it into a process by name only. Before every commit: `git grep -nE "AIza[0-9A-Za-z_-]{35}"` prints nothing. A recorded Gemini answer in `server/tests/fixtures/gemini/` is redacted (no key, no request id that could identify the account).
12. **What may be sent to Gemini (F-9):** the 15 labelled transcripts of D-493 (`a01`, `w01`-`w14`; never `a02`, a private recording's transcript) and the reference clip's transcript, text only. Never audio, never a frame, never another clip's words. Each real call is listed in the prompt's entry (which transcript, model, tokens).
13. **Real calls cost money.** TE-15 is 60 calls (15 × 2 models × 2 runs); at Flash prices that is cents, at Pro prices under a dollar (estimate). The local cap (`AI_MONTHLY_CAP_USD=5`) is the guard; never raise it locally without the founder.
14. **`.env` is sourced in every terminal** (`set -a; . ./.env; set +a`), so `PLAN_API_KEY` reaches the local API. **Never source `.env.deploy`:** it holds the production database's address, the mail relay and billing settings.
15. **The server's tests use a local fake for Gemini** (`PLAN_API_BASE_URL`), never the real API. Only P183, P188, P191 (one call), P206 (the whole clip) and P211 call the real one, from scripts or the local product.
16. **IndexedDB:** `DB_VERSION` stays 1; `plans-repo.ts` alone opens structure version 3 (D-469). A build with `ai_plan` off never upgrades anyone's database. A test opens through the clip path and asserts the version is unchanged.
17. **The plan request carries the ASR text, never the user's edits** (TS §40.7). `request-plan.test.ts` checks it.
18. **`run-pipeline.ts` with `ai_plan` off makes today's worker calls in today's order** (D-467). The call-sequence test is written before the change, against `b73fea5`'s behaviour, and must pass before and after.
19. **`messages.ts` is 678 of 700 lines.** New copy goes in `copy/plan.ts` (D-491).
20. **Media suites run on keyed builds.** `export VITE_ENTITLEMENT_TEST_PUBLIC_KEY=...` (Quick reference) before `pnpm build:e2e` and `pnpm build:e2e:flags`; unset it before committing.
21. **Playwright wipes `web/test-results/` every run.** Copy captures to `~/v6.2-review/` first.
22. **`target/` grows huge** (memory: 84 GB once). `cargo test -p <crate> --test <file>` per prompt; the workspace only in Setup and P212. `cargo clean -p` a crate if `target/` passes 30 GB.
23. **Docs and the changelog are edited with the Edit tool.** Never Python on Windows (CRLF), never a heredoc that holds backticks.
24. **pnpm scripts run in `cmd.exe` on Windows.** An environment prefix needs `sh -c "…"`.
